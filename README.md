# Deep Sen Portfolio

Static portfolio for GitHub Pages.

## Publish
1. Create a GitHub repository, e.g. `deep-sen.github.io` or `portfolio`.
2. Upload `index.html`, `style.css`, and `script.js`.
3. In GitHub: Settings → Pages → Deploy from branch → `main` → `/root`.
4. Replace the placeholder Email, GitHub and LinkedIn links in `index.html`.

No build step is required.
